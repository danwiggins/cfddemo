# Lab interpretation evidence matrix (S4)

This is a code-and-spec audit of the Lab interpretation boundary.
It is not assay validation. The Lab interpretation library is joined at read
time; its version is reported without changing stored result bytes or
execution identities (`traceback_lab/interpretation/engine.py`).

Inventory at v0.6.1: 88 entries across 17 algorithms; 84 have no reference and four show published means without intervals. Those four are fragment-size mode/mono/di-nucleosome values from platform-unspecified or Illumina background literature, and the mitochondrial share from Illumina WGS. Sixty entries carry scientific citations and 52 carry license callouts. This is a structural inventory, not independent verification of all 60 citations.

| Boundary | Current behavior | Evidence gap | Safe current state and downstream action |
| --- | --- | --- | --- |
| Cohort membership and circularity | `classify` accepts a prefiltered `Cohort` and gates on its supplied length: `<10` no reference, `10–29` exploratory min–max, `>=30` percentile and bootstrap interval. The caller, not this engine, owns exclusion. | Any caller that includes the target in supplied values can create a circular comparison; `classify` cannot detect that from values alone. | The cohort projection must exclude the scored source before D8 gates; retain 10→9 and 30→29 tests. Compare should consume that projection rather than construct a second scorer. |
| UI defended versus S0 completeness | `defended.exclusion` checks status, half-depth usability, split stability, tier, citation, and positive control where applicable. `headline` can say “result is defended.” It receives no full-kit completeness flag. | The approved handoff requires complete source input before a full-run scientific claim; an incomplete input cannot meet that gate. Thus the D24 UI term and full-run scientific claim have different scopes. | Preserve D24 software behavior pending a versioned policy decision. Label partial source evidence separately in operator reporting; never infer scientific completeness from a UI row or synthetic example. S5 should test the displayed context, and L0 should decide any policy change. |
| Actual modified-base model | `cell_origin.header_model` accepts a single string from BAM `@RG`, including an unverified placeholder, and `run` forwards it to signed measurement parameters. | A single declared string can be a placeholder rather than the actual vendor model. The software currently cannot derive the real model from it. | Keep model identity unknown for scientific interpretation. The owner must supply verified model provenance before a biological claim or a versioned code policy. S1 compatibility must not mistake the placeholder for known matching chemistry. |
| PMD input terms | `licenses.yaml` labels Zhou PMD data terms unknown; the PMD file is operator supplied and digest pinned. | A citation request is not a distribution license. | Retain `zhou-pmd-terms-unknown`; S2 asset handling must record terms without vendoring or downloading it implicitly. Owner resolves rights and PoN method. |
| Existing library metadata | `library.yaml` uses tier, origin tier/platform, depth, reference kind, performance or missing reason, stability, citations and `citation_checked`; `licenses.yaml` resolves license callouts. | These fields do not by themselves validate source applicability to this ONT kit. Existing published figures include other platforms and populations. | Keep published means as `no_reference`, and platform-specific performance as footnotes. Do not promote an Illumina/WGBS figure to an ONT healthy range. Independent source audit is needed before changing any displayed figure. |
| C1 frag-x-meth | L0 froze an exploratory per-molecule metric: among D21 eligible derived-masked molecules with ≥4 C+m CpG calls, calculate each read's fraction of argmax 5mC among C+m sites. `short_fragment_hypomethylation_delta` is mean(long 151–220 bp) minus mean(short 100–150 bp). | No peer-reviewed source has yet been verified for this exact ONT estimator, binning or denominator; biological validity is not established by software checks or the read-time entry. | The v0.6.1 entry is `SPECULATIVE`, `reference: none`, `performance: null`, with no ONT normal range and no scientific citation. Its formula note records the denominator and empty-group behavior; a null delta explicitly names the missing size group; `citation_checked` confirms only that no scientific citation is displayed. Keep this read-time entry aligned with the versioned C1 formula. |
| C2 breakpoint-motifs | L0 froze `cpg_near_end_fraction`: D21 eligible molecules supply aligned-span start and end-1; the share of valid ends within ±10 bp inclusive of a reference CG C coordinate is the scalar. No patent or data rights are implied. Keep read-time text aligned with the versioned formula, artifact and registry integration. |
| Remaining threshold decisions | Sex-check thresholds and mitochondrial denominator are outside this slice. | No approved replacement thresholds or denominator provenance. | Preserve current semantics; request an explicit owner decision before a versioned change. |

The synthetic acceptance file `tests/lab/test_interpretation_evidence.py` records

that the kit input is complete, or that the actual modbase model is known.
